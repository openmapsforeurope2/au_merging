## [1.1.0] - 2026-09-14

### Added
- Added a command-line parameter to specify the target database name.

### Changed
- Updated the processing to consistently exclude destroyed objects throughout the whole process.
- Updated the configuration to specify the source administrative level for each target level and country.
- Changed the output table suffix so that it is no longer combined with the country code and is based only on the user-defined suffix.
- Updated the SOCLE dependency.
- Removed the database configuration from the EPG parameter file.
- Adapted the application to the IGN-MUT deployment environment.
- Improved documentation and diagnostic logging.
